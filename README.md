# anil-sprites
Sprites de Pokémon del juego **Pokémon Añil Super Randomlocke**, servidos vía GitHub Pages
para el tracker web. Carpetas: `front/` (normal) y `front-shiny/` (shiny), nombradas por el
ID interno del juego (ej. `BLASTOISE.png`, `BLASTOISE_2.png`). El super-shiny reutiliza el
shiny (salvo 3 especies con matiz propio, que la web recolorea por CSS).
